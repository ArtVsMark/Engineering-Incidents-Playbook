Части лесенки Python на значке различаются цветом, а не только подсказкой (решение владельца 16.10, вариант B). Жёлтый — версия лесенки, которую проект не проверяет: это отставание, и чинится оно правкой проекта. Тёмно-серый — сборки для CI ещё нет: в манифесте `setup-python` серии нет, проверять нечем, и чинить ничего не надо. Серый остаётся «проверка не проводилась». Недостающая ступень без сборки теперь тоже тёмно-серая, а не жёлтая: невышедшую версию не проверяет никто. Подпись «версия ещё не вышла» заменена на «сборки для CI ещё нет»: альфа 3.16 могла выйти на python.org, но в манифесте её нет.

> Правилом не становится, потому что это решение о виде, а не поломка.

Соседи: зона Python в `python-badge` и `project-badge` у каждого проекта семьи. У грейдера `3.15` станет жёлтой, `3.16` тёмно-серой; у механизмов так же; у каталога `3.16` из серой станет тёмно-серой.
