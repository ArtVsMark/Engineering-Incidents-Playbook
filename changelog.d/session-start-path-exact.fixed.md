Строка статуса хука старта сверяет PATH окна по той же строке, которую хук пишет в файл окружения, и целиком, а не по подстроке пути: подстроку выполнял и чужой комментарий или `.venv/bin2`, а провал собственной записи оставался зелёным. Строка PATH собирается в одном месте для записи и для сверки. Находка обзора #676.

> правилом не становится, потому что это частный случай уже записанного: утверждение проверки шире того, что она проверяет (183)
