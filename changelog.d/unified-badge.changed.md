Значок Python стал единым значком состояния «Python 3.14 3.15 │ linux windows mac │ coverage │ release / PyPI │ version» (решение владельца 1 октября): зоны разделены просветом, версия последней. Покрытие и версия берутся из файлов значков, которые проект уже собирает, а не меряются второй раз; «release / PyPI» показывает старшие два числа выпуска и зеленеет, когда номер на PyPI совпадает с последним выпуском, краснеет при расхождении и сереет, если проект на PyPI не публикуется. Отдельные значки «Релиз», «Версия» и «Покрытие» с витрины сняты как дубли; в наборе вопросов витрины ответы на них, а также на «зелены ли проверки», теперь ведут в единый значок. Проекту, у которого часть кода исполняется только на своей ОС, зона покрытия показывает второе число — покрытие по всем ОС: `coverage / all (os) 72% / 85%`, а без него — просто `coverage 72%`. Действие `python-badge` получило входы `coverage-json`, `coverage-all-json`, `version-json` и `pypi`; без них соответствующие зоны серые, так что подключение по `v1.5.0` продолжает работать.
