Правило 186: код возврата, переиспользованный между режимами, читается вместе с
режимом — и разводит их издатель, а не читатель. Приехало предложением из
`Claude-Code_Usage-Token`, где наш `link_trails.py` красил прогон по расписанию
удачной записью три раза подряд; второй замер нашёлся у нас же — поведение было
не оплошностью, а задокументированным.
