Каталог переехал на Python 3.14 по-настоящему, а не только номером: из всех файлов убран `from __future__ import annotations` (на 3.14 аннотации ленивые сами, PEP 649/749), `except (A, B):` без `as` записан без скобок (PEP 758), устаревшие импорты и срезы заменены. Четыре загрузочных файла стража толчка оставлены в грамматике системного python окна (3.11): их исполняют до того, как собрано окружение на планке. Новый гейт `scripts/check_py_style.py` держит стиль на планке (и `except*` тоже); у загрузочных файлов граница разбора грамматикой окна замерена тестами — одинаковые кавычки внутри f-строки она пропускает, и это названо; версия окна — ручное число по замеру, сдвиг образа гейт не увидит: требования выводятся из `requires-python`, ruff получает цель из неё же, и следующий подъём планки ужесточит проверку сам.

Соседи: сужения нет — гейт прочёл замену `'{\n  "schema": "%s"\n}\n' % схема` на f-строку в фикстуре tests/test_check_prose.py как убранный элемент; собираемый текст тот же (сверено: набор test_check_prose зелёный), меняется только запись форматирования (ruff UP031).
