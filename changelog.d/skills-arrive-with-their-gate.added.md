У окна Claude Code в этом репозитории появились навыки, и первым — `/incident-triage`: первичный разбор инцидента инженерной работы (красная `main`, упавший гейт или прогон по расписанию, стоящая очередь, молчащее окно) по правилам каталога, с каждой ссылкой, поставленной по разделу «Применимость», и с шкалой тяжести на трёх примерах из этого же репозитория. Вместе с ним заведён гейт `scripts/check_skills.py`: список навыков в `.claude/skills/README.md` сходится с деревом в обе стороны, у каждого навыка заголовок площадки, строка читателя и разделы заготовки `templates/skill-template.md`, которая впервые применяется у самого каталога (155, 197). Загрузка подтверждена прогоном, а не чтением: CLI находит навык, вызывает его по `/incident-triage`, а соседний `README.md` за навык не принимает (139).
