Прогон `python-next` гоняет тесты каталога на предрелизном Python 3.15 — на толчке в общую ветку, раз в неделю и по кнопке, — затем, чтобы заранее знать, будет ли каталог на нём работать (решение владельца 1 октября). В README два значка состояния: «Python 3.14» по `ci.yml` и «Python 3.15 (пред.)» по `python-next.yml`, каждый зеленеет и краснеет сам. На изменении `python-next` не просыпается (084), а его красное не морозит очередь слияний и не поднимает тревогу дежурного: `automerge.yml` и `main-red.yml` исключают его одним именем. Гейт `check_python_version.py` узнаёт такой прогон по `allow-prereleases: true` в том же `with:` и не требует от него версии прочих прогонов, но требует, чтобы она была выше их: предварительный прогон на текущей версии ничего не спрашивает.
