`check_overlap` на локальном пути снова видит пересечения. Вывод `git diff --name-only -z` резался голым `split()`, а NUL пробелом не считается: все файлы ветки склеивались в одно имя с `\0` внутри, и проверка отвечала «пересечений нет» на любом дереве — ложный зелёный у механизма 133. Теперь список режется по NUL, и набор впервые проходит локальный путь на настоящем репозитории: прежние случаи шли только через площадку, потому что ветки из теста в дереве каталога нет. Нашла витрина замером на v1.9.0 (#762). Соседи: `-z` читают семь скриптов, остальные шесть режут по NUL верно.

> правилом не становится, потому что это нарушение уже действующего 165: «разбирай вывод по NUL» — его вторая половина, и гейт `check_subprocess` держит только первую (`-z` в команде).
