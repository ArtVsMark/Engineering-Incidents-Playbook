Зона Python на значке показывает у всех проектов одну лесенку версий семьи — сейчас `3.14 3.15 3.16` (решение владельца 16.10). Лесенка — это версии, которые проверяет сам каталог: планка, обязательная работа и предварительная проверка. Она берётся из дерева каталога на теге действия, тем же разбором, что рисует его собственный значок. Версия лесенки, которую проект не проверяет, — серая часть с причиной «проектом не проверяется», а не пропавшая часть. Так отставание по версиям видно на значке у всех, а первые строки соседей одной длины.

> Правилом не становится, потому что это решение о виде, а не поломка.

Соседи: зона Python в `python-badge` и `project-badge` у каждого проекта семьи. У грейдера появятся серые `3.15 3.16`, у механизмов — серая `3.15`; у каталога ничего не меняется.
