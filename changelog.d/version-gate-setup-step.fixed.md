Гейт версий ищет шаг установки по строке `uses: actions/setup-python@…`, а не по слову в тексте: упоминание `setup-python` в комментарии выше вызова делало установку «ранней» и прятало вызов python до неё. И шаг установки без числа в `python-version` — выражение `${{ … }}`, файл `.python-version`, версия раннера — теперь находка: такую версию не с чем сверить с планкой, и ниже неё она проходила молча. Находки обзора #678.

Соседи: работы в `.github/workflows/` (`мимо_планки`) — тот же поиск установки подстрокой и тот же молчаливый шаг без числа, исправлены тем же разбором шагов; значок версии и факты (`in_workflows`) не тронуты — они читают только литералы и о шагах без числа не утверждают.

> правилом не становится, потому что это частный случай уже записанного: гейт проверяется тем, что обязан отвергнуть (140), а суженный признак называет соседа (195)
