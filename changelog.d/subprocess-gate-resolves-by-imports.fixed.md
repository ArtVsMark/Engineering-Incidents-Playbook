Гейт вызовов наружу разрешает предмет по импортам разбираемого файла, а не по последнему звену имени. Закрыта обратная дыра: вызов через `from subprocess import run as ...` не находился вовсе, и гейт зеленел ровно за то, чего не умел увидеть. Ложные находки на своих функциях с именем `run` — их в дереве двенадцать — стали невозможны по построению, а не по счастливой случайности узкого триггера.
