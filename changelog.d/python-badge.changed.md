Значок Python в README — одна картинка из частей «Python │ 3.14 │ 3.15 │ linux │ windows │ mac» (решение владельца 1 октября). «Python» окрашен исходом основного CI, каждая версия — исходом своего прогона на `main`, каждая ОС — исходом работ основного CI на ней: зелёный — пройден, красный — не пройден, серый — прогона с вердиктом не было или на этой ОС не проверяли. Версии берутся у прогонов, ОС — у раннеров решающего прогона, а не пишутся рукой: нужна ли проекту мультиплатформенность, решает сам проект, а значок показывает это честно: у каталога, который гоняется только на Linux, windows и mac серые. Значок собирает `scripts/python_badge.py` в `badges.yml`, а потребителям он отдаётся составным действием `python-badge` (файл основного CI — вход `ci-workflow`; версия, идущая матрицей, подписывается планкой из `requires-python`), который теперь просыпается и по завершении `ci` и `python-next` на общей ветке — иначе цвет отставал бы на слияние. Если площадка не ответила о прогонах, значок не перерисовывается серым, а остаётся прежним: «не спросили» не значит «не проводилась». Два прежних значка shields сняты.
