README каталога и `CONNECT.md` показывают одну картинку — значок проекта в две строки `project.svg` — вместо двух: `python.svg` и `family.svg` у каталога, `project.svg` механизмов и `family.svg` у потребителя (#844). Прежние действия `python-badge` и `family-badge` остаются для тех, кто ещё не перешёл. В `CONNECT.md` названо, почему механизмам подключать `project-badge` можно только после того, как их `step-facts` перестанет рисовать свой `project.svg`: иначе у одного файла два писателя.
Набор вопросов витрины `.rules/showcase.json` отвечает на «проверки», «выпуск», «версия» и «покрытие» зонами первой строки `project.svg`, а не `python.svg`: картинка в README теперь одна.
