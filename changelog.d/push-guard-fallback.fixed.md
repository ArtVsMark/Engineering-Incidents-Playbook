Запасной разбор стража толчка — тот, что работает, когда в окне нет интерпретатора планки, — закрывает и непрямые формы толчка: `git -C путь push`, `git p''ush`, `git "push"`, табуляцию между словами, `git --no-pager push`. Раньше он ловил только литерал «git push», и такие толчки уходили непроверенными. Разбор смотрит только на поле `command` входа, а не на весь JSON: слово `git` в пути рабочего каталога не закрывает посторонних команд. Граница сдвинута в сторону закрытия — `git stash push` в сломанном окне тоже закрыт; косвенный толчок (`c=push; git $c`, подстановка, алиас) не видит ни этот разбор, ни сам страж. Находки обзоров #672 и #710.
