Подключение проекта к каталогу собирается одной командой: `scripts/onboard_consumer.py --repo владелец/имя --out ПАПКА` кладёт ответ по каждому правилу, пустой файл предложений и рабочий процесс с тегом, взятым из контракта. Отдельно в контракте описан выход: без него реестр копит объявленных и молчащих потребителей.
