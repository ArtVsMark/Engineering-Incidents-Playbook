Гейт ответа (`scripts/check_bindings.py`) требует у «не применимо» одну из двух законных форм правила 205: предикат по дереву — путь, команду или имя в обратных кавычках, которое можно прогнать сегодня, — либо названное СОБЫТИЕ с причиной, почему предикат здесь вырождается. Слово из словаря ответа в кавычках предикатом не считается. Ответ без обеих форм отвергается: неприменимость, которую нечем перечитать, держится рассуждением, а не деревом. Первым же прогоном гейт поймал ответ каталога по 020 — он переписан в форму события.
