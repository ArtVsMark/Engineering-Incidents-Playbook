README на обоих языках говорит, чем каталог является для разных читателей. Для внешнего проекта он — правила, а значки и договор фактов по желанию. Для семьи он — главный держатель контрактов, её мозг: здесь все договоры, код единого значка и эталон для сверки. Цена второй роли названа: каталог — единая точка (#842, решение владельца 15.10).

Абзац «каталог отдаёт наружу механизмы, а не только текст» сокращён до «механизмы по желанию — перечислены в CONNECT.md одним списком»: так он не спорит с ролью «внешним — правила», а витрина остаётся в пределе 1000 слов с запасом.

Перечень договоров каталога назван поимённо — выгрузка, ответ, предложения, манифест, факты; шаги конвейера держат механизмы (обзор #848). Цена второй роли названа тем, что делает код: без сводки каталога у каждого проекта краснеет шаг семейного значка, а картинка застывает на прошлой (`family_check.py`, исход 2).
