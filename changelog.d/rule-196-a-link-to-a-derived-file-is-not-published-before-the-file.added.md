Правило 196: ссылка на производный артефакт не уезжает в общую ветку раньше,
чем артефакт нарисован (ArtVsMark/ArtVsMark#145, ArtVsMark/ArtVsMark#147).
Принято из предложения витрины профиля, где соблюдение измерено как 0 из 2 —
правило нарушено своим же автором в день написания. Гейт «файл существует» здесь
незаконен по построению: производное живёт вне общей ветки, и проверка краснела
бы на каждой правке витрины. Предмет каталога — 21 ссылка на ветку `badges` в
четырёх документах, и число уточнялось дважды внешним взглядом: восемь ссылок
живут внутри URL-кодированного параметра `url=` у shields.io и сырым поиском не
находятся.
