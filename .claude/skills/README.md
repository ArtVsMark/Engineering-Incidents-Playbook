# Навыки окна · Window skills

> **Читатель:** участник — какие навыки есть у окна Claude Code в этом репозитории и как их звать.

Навык — инструкция, которую окно читает **в момент вызова**, а не при старте.
В этом его сила против свода: правка `AGENTS.md` живому окну не видна вовсе
([047](../../rules/ru/047-rule-change-restarts-the-windows.md)), а навык
перечитывается при каждом вызове. И в этом же его слабость против гейта:
**навык не краснеет** — он ничего не отвергает, а срабатывает по суждению
модели ([`templates/skill-template.md`](../../templates/skill-template.md)).

Навыки здесь — про инциденты **инженерной работы**, о которых и написан каталог:
покрасневшая общая ветка, упавший гейт или прогон по расписанию, замёрзшая
очередь, ошибка окна. Каждый шаг навыка ссылается на правило каталога, и
ссылка поставлена по разделу «Применимость» этого правила, а не по подходящей
фразе ([204](../../rules/ru/204-a-citation-is-checked-by-applicability.md)).
Рычагов эксплуатации — флагов, ограничения частоты, режима деградации,
масштабирования — в каталоге нет, и навыки их не изобретают: правило без
инцидента в каталог не идёт.

## Список

| Навык | Когда звать |
|---|---|
| `incident-triage` | что-то покраснело или встало, и надо понять, что сломано, насколько и что делать первым |
| `incident-mitigation` | разбор уже назвал, что красное, и надо выбрать меру — обратимую, с проверкой эффекта до её выполнения |
| `incident-communications` | об инциденте надо написать — владельцу, в изменение, в задачу, следующему окну, потребителям — и перед отправкой написанного |

Список один, и он сверяется с деревом: навык, названный здесь, обязан
существовать, существующий — быть названным (`scripts/check_skills.py`).

## Как звать

Окно Claude Code открывается **из корня этого репозитория** — навыки лежат в
его `.claude/skills/` и действуют только здесь. Отдельной установки нет.

- **Явно:** `/incident-triage` — с описанием случая после имени или без него:
  `/incident-triage main покраснела после слияния #556`.
- **Словами:** «общая ветка красная, разберись», «почему очередь не сливает
  изменение», «прогон по расписанию упал третий день подряд». Окно само решает,
  звать ли навык, — по его описанию, строке `description` в заголовке `SKILL.md`.
  Поэтому описание говорит, **когда** звать, а не что внутри.
- **Что загружено:** `/skills` показывает навыки текущего окна.

Имя навыка — это имя его каталога: `.claude/skills/incident-triage/` даёт
`/incident-triage`. Поле `name` в заголовке обязано с ним совпадать — два имени
одного навыка расходятся молча ([022](../../rules/ru/022-one-canonical-document.md)).

## Как добавить навык

1. Каркас — из [`templates/skill-template.md`](../../templates/skill-template.md),
   а не от соседнего навыка: соседа собирали по прежней заготовке.
2. Раздел «Зачем это существует» называет **инцидент** с числами. Поломки не
   было — навык не нужен: он займёт место и создаст видимость.
3. Строка в таблицу выше. Без неё гейт отвергнет навык: о навыке, про который
   молчит список, знает только окно.
4. `python scripts/check_skills.py` — список против дерева, заголовок, читатель
   и разделы заготовки. Три исхода: `0` чисто · `1` находки · `2` проверка не
   отработала.

Чего гейт не проверяет — сработал ли навык и верно ли применено правило, на
которое он ссылается. Первое — суждение модели, второе — вопрос ревью.

## In English

Claude Code skills of this repository, for incidents of **engineering work** —
a red main branch, a failed gate or scheduled run, a frozen merge queue, a
window's mistake. Every step cites a catalogue rule, checked against that
rule's "applicability" section. The skills are written in Russian, like the
window's working language. Open Claude Code at the repository root and call
`/incident-triage`, or describe the situation in words; `/skills` lists what
is loaded. The table above is the single list of skills, and
`scripts/check_skills.py` holds it against the tree.
