# У задания исполнителя есть числовые границы

**Область.** параллельная работа

**Ступень.** 2 — конвейер и CI

**Правило.** В задание пишутся числа: предел размера каждого поля ответа,
бюджет обращений к инструментам, список типов файлов, которые открывать нельзя.
Без чисел исполнитель выбирает их сам — и выбирает плохо.

## Инцидент

Волна параллельных исполнителей обрывалась одинаково: работа выполнена,
транскрипты по 180–380 килобайт, а финальный ответ **не доехал**. В журнале —
только отметка о старте, ни одного результата.

Три числовые меры дали измеримый эффект, каждая своя:

| Мера | Эффект |
|---|---|
| ограничения на длину строк и число элементов в схеме ответа | **вдвое** меньше расхода на срез |
| бюджет обращений к инструментам (около 25) прямо в задании | волна вдвое дешевле предыдущей при том же выходе |
| запрет открывать двоичные файлы (изображения, шрифты) | снял зависания без прогресса |

Последнее стоит отдельного слова: один исполнитель завис на чтении двоичного
файла — **180 секунд шесть раз подряд** без единого признака прогресса. Он не
падал и не заканчивал; он просто расходовал время.

## Почему

Исполнитель, которому не назвали границу, ведёт себя разумно **по-своему**: пишет
настолько подробно, насколько может, и открывает всё, что кажется относящимся к
делу. Обе привычки полезны в маленькой задаче и разрушительны в большой — а
разницу между ними видит только тот, кто ставил задачу.

Ограничение на **размер ответа** попадает в самое дорогое место: отказ приходит
на выдаче, когда работа уже сделана и оплачена. Ограничив поля, уменьшаешь не
качество, а вероятность потерять всё.

Бюджет обращений работает иначе — он заставляет **выбирать**. Без него
исполнитель обходит всё подряд в произвольном порядке; с ним начинает с
существенного, потому что знает, что попыток конечное число.

Запреты на типы файлов — про то, что исполнитель не может знать заранее: какие
входы для него бесполезны и дороги. Это знание хоста, и передать его надо явно.

## Практические границы

- числа стоят **в задании**, а не в голове того, кто его писал;
- у каждого строкового поля ответа — предел длины, у каждого списка — пределы
  числа элементов;
- бюджет обращений называется числом, а не словом «экономно»;
- запреты перечисляют типы и говорят, **что делать вместо** («описание файла
  брать из соседнего текста»);
- числа берутся из замера предыдущей волны и корректируются, а не выдумываются
  один раз навсегда.

## Применимость

**Работает** для параллельных исполнителей с ограничением на объём ответа и
платой за обращения.

**Не работает** для одиночной интерактивной работы, где границу задаёт человек
по ходу.

**Признак нужды:** ответы теряются на выдаче или приходят обрезанными.
