# Хранилище выбирается по жизненному циклу данных, а не по удобству

**Область.** архитектура, данные

**Ступень.** 4 — код и тесты

**Правило.** Данные с разным сроком жизни и разным способом записи не сливают в
одно хранилище. Общий файл склеивает несклеиваемое и отнимает свойства, ради
которых формат выбирали.

## Инцидент

Персистентности накопилось три вида: история прогонов, кэш и очередь
недостающего. Соблазнительное решение — единая база на всё.

Отклонено, и доводы записаны: смешивает **разные жизненные циклы**, усложняет
очистку и сброс, повышает конкуренцию за один файл. Очистить кэш, не тронув
историю, в общем хранилище становится отдельной задачей вместо удаления файла.

Второй отклонённый вариант — обратный: мигрировать **всё** на базу. Минус
конкретный: журнал статистики теряет свойство «только дописывание», а вместе с
ним дешёвое слияние при параллельной записи из разных процессов.

Выбрали середину: общий **код** доступа к базе — да; общий **файл** — нет.
Мигрирована только та часть, которой действительно нужны транзакции; остальное
осталось в своих форматах.

## Почему

Формат хранения — это набор свойств, а не вкус. «Только дописывание» даёт
устойчивость к параллельной записи и простое слияние. Транзакции дают
согласованность. Отдельный файл даёт **удаление одним движением**. Свойства не
складываются: слив всё в одно, получаешь пересечение, а не объединение.

Второе: жизненные циклы задают **операции**, которые обязаны быть дешёвыми. Кэш
чистят целиком и часто. Историю не чистят никогда. Очередь опустошается по мере
обработки. Общее хранилище делает дорогой ту операцию, которая должна быть
самой дешёвой.

Третье: единый файл — единая точка конкуренции. Три независимых потока записи
начинают ждать друг друга без всякой на то причины.

## Практические границы

- общий **код** доступа — норма и польза; общий **файл** — решение, требующее
  обоснования;
- у каждого хранилища записано: срок жизни, способ записи, кто чистит и как;
- миграция выборочная: переносится то, чему нужны свойства нового формата, а не
  всё сразу «для единообразия»;
- если формат выбран ради свойства (дописывание, слияние, атомарность), это
  свойство называется прямо — иначе следующий рефакторинг его отнимет.

## Применимость

**Работает** там, где видов данных больше одного и они живут по-разному.

**Не работает** при единственном виде данных: там разделение — лишняя сущность.

**Признак проблемы:** «почистить кэш» стало отдельной задачей вместо удаления
файла.
