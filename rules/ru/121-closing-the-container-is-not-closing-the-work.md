# Закрытие контейнера — не доказательство закрытия работы

**Область.** процесс, аудит

**Правило.** Эпик, веха, спринт закрываются по своим критериям, единицы работы —
по своим. Завершение доказывается **счётчиком незакрытых единиц**, а не тем, что
контейнер выглядит пустым.

## Инцидент

Документ аудита уехал в архив, когда закрылись **все одиннадцать** подэпиков его
основного эпика. Формально безупречно: контейнеры пусты, задачи закрыты, вопрос
выглядит решённым.

Ревизия вернулась к этому аудиту через полторы недели и нашла **десять живых
дефектов**, числившихся исправленными, — в том числе один, воспроизводящийся
обычным прогоном.

Причина проста: закрытие подэпика означало, что по нему прошла работа, а не что
**каждая находка** внутри получила исход. Часть находок не была ни закрыта
номером изменения, ни отклонена с причиной — они просто перестали упоминаться.

Правило по итогам: перед архивацией — проверка **счётчиком**. Находок без номера
изменения и без пометки об отклонении должно быть **ноль**.

## Почему

Контейнер закрывается по признаку, который легко наблюдать: нет открытых
дочерних задач. Единица работы закрывается по признаку, который наблюдать
труднее: у неё есть исход. Между этими признаками помещается всё, что успело
выпасть — переформулированное, разбитое на части, потерянное при переносе.

Второе: **архивация закрывает вопрос**. К архиву не возвращаются, его не
перечитывают, по нему не строят план. Ошибиться в момент архивации — значит
похоронить живые дефекты так, что найти их сможет только случайная ревизия.

Третье, общее: у любого перехода «работа завершена» должен быть **счётный
критерий**, а не оценочный. «Всё сделано» не проверяется; «единиц без исхода
ноль» проверяется одной командой и не зависит от того, кто смотрит.

## Практические границы

- у каждой единицы работы — явный исход: закрыта с номером изменения либо
  отклонена с причиной; молча исчезнувшая единица считается открытой;
- перед архивацией счётчик выполняется **обязательно**, а не при подозрении;
- **разные рубежи не обязаны совпадать** и не путаются: разблокировка следующей
  фазы может требовать закрытия только тех единиц, что влияют на её предмет, а
  архивация — закрытия всех, включая не влияющие ни на что;
- закрытие контейнера не переносит документ никуда само: перенос — отдельное
  действие с отдельным условием.

## Применимость

**Работает** для аудитов, эпиков, вех, приёмки работ по чек-листу.

**Не работает**, если единицы неисчислимы («улучшить производительность») —
тогда сначала нужен счётный предмет.

**Признак нарушения:** ревизия закрытого находит живое.
