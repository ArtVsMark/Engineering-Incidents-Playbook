# Что инструмент создал — он обязан уметь удалить

**Правило.** У всякого накопления, заведённого продуктом, есть штатная команда
удаления. «Удалите файл вручную» — не способ: пользователь не создавал этот файл
и не обязан знать о нём.

## Инцидент

Продукт вёл локальный журнал обучения. Выключатель записи был: он переставал
**писать**. А убрать уже накопленное можно было только удалив файл базы руками —
вместе с двумя служебными файлами рядом, о существовании которых пользователь
знать не мог.

То есть управление данными выглядело полным, а на деле покрывало только будущее.
Прошлое оставалось на диске, и единственный путь к нему требовал знания
внутреннего устройства.

Починка — отдельная команда удаления, и с двумя деталями. Первая: без уточнения
чистится **и** сопутствующая статистика — это те же личные данные, и оставлять
их значило бы выполнить обещание наполовину. Вторая: есть предварительный
просмотр — что именно будет удалено, до того как это произойдёт.

## Почему

Право удалить — часть права владеть. Продукт, создающий накопление на чужой
машине, берёт на себя обязательство: тот, чьи это данные, должен управлять ими
средствами продукта, а не файлового менеджера.

Второе: «удалите вручную» требует **знания внутреннего устройства** — где лежит,
как называется, какие файлы рядом. Это знание пользователь не может получить
законным путём и не обязан иметь. Инструкция, требующая его, равносильна отказу.

Третье, часто пропускаемое: выключить запись и удалить записанное — **разные
операции**. Первая про будущее, вторая про прошлое, и наличие первой создаёт
ложное впечатление, что есть и вторая.

## Практические границы

- команда удаления перечисляет **все** места, где продукт накопил данные:
  основное хранилище, служебные файлы рядом, кэши, статистика;
- есть предварительный просмотр и подтверждение — удаление необратимо;
- удаление доступно и выборочно (по объекту), и целиком;
- в документации сказано, **где** данные лежат и что именно удаляется: это часть
  обещания, а не техническая деталь;
- то же правило действует на отзыв согласия: разрешение снимается тем же
  средством, каким давалось.

## Применимость

**Работает** для журналов, кэшей, историй, накопленной статистики, настроек,
данных согласия.

**Не работает** для того, что требуется хранить по внешним обязательствам, —
там граница объясняется, а не молчится.

**Признак нарушения:** в ответе на «как это убрать» есть путь к файлу.
