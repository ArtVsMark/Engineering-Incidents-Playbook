# Умолчание выбирается в пользу пользователя, а не продукта

**Область.** приватность, продукт

**Ступень.** 5 — всё остальное

**Правило.** Когда сбор данных выгоден продукту и не нужен пользователю,
умолчание — **выключено**. Компенсируется не включением по умолчанию, а
удобством включить и ненавязчивым напоминанием.

## Инцидент

Запись истории прогонов делает продукт умнее: чем больше накоплено, тем полезнее
рекомендации. Прямой путь — включить по умолчанию, чтобы наполнялось само.

Выбрали обратное: **выключено по умолчанию**, плюс удобный переключатель в меню
и мягкое напоминание. Продукт от этого наполняется медленнее — и это принятая
цена, а не недосмотр.

Отдельно отклонили третий вариант, который кажется самым честным: **спросить при
первом запуске**. Доводы записаны: лишнее трение на старте, ломает неинтерактивные
сценарии и автоматизацию, усложняет тесты. То есть «спросить» — не нейтральное
решение, а перенос стоимости на всех, включая тех, кто запускает продукт из
скрипта.

Показательно, что для веб-оболочки умолчание другое — там сессия по смыслу
интерактивная. Умолчание выбирается **по сценарию**, а не одно на весь продукт.

## Почему

Умолчание — это решение, принятое **за** пользователя, и в этом вся его сила:
им пользуется подавляющее большинство. Значит вопрос не «что удобнее нам», а
«что человек выбрал бы, если бы знал», — и при сборе его данных ответ известен
заранее.

Второе: цена ошибки несимметрична. Не собранные данные — упущенная польза,
восполнимая. Собранные без ведома — потерянное доверие, невосполнимое; и узнают
об этом обычно не от нас.

Третье, про «просто спросить»: интерактивный вопрос выглядит компромиссом, но
у него есть невидимая жертва — **неинтерактивные сценарии**. Запуск из скрипта,
из конвейера, из теста не может ответить на вопрос и либо виснет, либо получает
случайное умолчание.

## Практические границы

- выключено по умолчанию — включается **одним движением**, а не поиском в
  конфигурации;
- напоминание мягкое и конечное: одноразовый намёк, а не повторяющийся баннер;
- умолчание может различаться по сценарию, и различие объясняется, а не
  подразумевается;
- вопрос при первом запуске — отдельное решение со своей ценой: он ломает
  автоматизацию и требует пути «ответа нет».

## Применимость

**Работает** для сбора данных, телеметрии, отправки наружу, автообновлений.

**Не работает** для того, без чего продукт не выполняет обещанного, — там
выключенное умолчание превращает функцию в скрытую.

**Признак ошибки:** умолчание объясняется пользой для продукта, а не для того,
кто им пользуется.
