# Ссылка на задачу уместна в журнале и вредна в объяснении

**Область.** документация

**Правило.** Номер задачи — это датировка. В логах она нужна, в тексте «как это
работает» — мешает.

## Инцидент

Номера задач расползлись по всей документации. Фразы вида «фиксированный
словарь тегов вместо предикатного языка — упрощение (issue NNN)» встречались в
описаниях того, как система устроена.

Читатель, пришедший понять устройство, получал ссылку на обсуждение
трёхлетней давности вместо ответа. А сама ссылка со временем теряла смысл:
контекст задачи забывался быстрее, чем менялся код.

## Раскладка по зонам

| Где | Номер | Почему |
|---|---|---|
| журнал изменений, архив | **обязателен** | это лог: номер = ссылка на изменение |
| разборы, аудиты | уместен | находки привязаны к задачам по природе |
| решения об архитектуре (ADR) | уместен в разделе «контекст» | задача — часть ответа на «почему решили так» |
| проектные документы | только как **идентификатор требования** | на него ссылаются другие документы и код |
| служебное для автоматики | минимум | указатели |
| **документация «как работает»** | **нет** | отвечает на «как сейчас», а не «когда появилось» |

## Как переписать, если номер кажется нужным

Перефразируйте так, чтобы объяснялся **компромисс**, а не датировалось решение.

Было: «фиксированный словарь вместо предикатного языка — упрощение (issue NNN)».
Стало: «фиксированный словарь вместо предикатного языка — сознательное
упрощение: предикаты дают гибкость ценой непроверяемости».

Второй вариант отвечает на вопрос читателя. Первый отправляет его читать
переписку.

## Механизм

Правило машинное: проверка держит объясняющие документы на нуле ссылок, а зонам
с допустимым «хвостом» задаёт **бюджет**.

Ключевая деталь: **бюджет только снижают, никогда не повышают**. Рост означает,
что журнал снова пополз в объясняющий текст. Порог, который можно поднять при
неудобстве, не защищает ни от чего.

## Применимость

**Работает** для проектов с трекером и документацией одновременно.

**Не работает** в проектах, где документация и есть трекер.

**Обобщение переносимо:** приём «бюджет, который только снижают» годится для
любой постепенной чистки — размер файла, число исключений линтера, количество
пропущенных тестов.
