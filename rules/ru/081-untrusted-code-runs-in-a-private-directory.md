# Чужой код запускают из приватного каталога, а не из общего временного

**Область.** безопасность

**Правило.** Файл, который будет исполнен, кладут в каталог, созданный для
одного запуска и доступный только владельцу. Общий временный каталог — это
недоверенный вход, а не удобное место.

## Инцидент

Песочница сохраняла присланный код во временный файл и запускала его. Каталог
брался общий системный — то самое место, куда пишут все.

Дефект в том, что интерпретатор ставит **каталог запускаемого файла первым** в
путь поиска модулей. Значит любой файл с именем модуля стандартной библиотеки,
заранее подложенный в общий каталог, подменил бы её для чужого кода — и подмена
случилась бы **до** первой строки этого кода.

Подложить такой файл может кто угодно, у кого есть учётная запись на той же
машине; ждать он может сколько угодно — запись живёт до перезагрузки.

Починка: каталог создаётся под один запуск, с правами только для владельца, и
удаляется целиком по завершении.

## Почему

Общий временный каталог обладает свойством, которое легко упустить: **в него
пишут другие**. Всё, что вы туда положите, соседствует с чужим содержимым, а
всё, что вы оттуда прочитаете или неявно подхватите, может быть чужим.

«Неявно подхватите» — ключевая часть. Опасность здесь не в том, что кто-то
прочтёт ваш файл, а в **правилах разрешения имён**: путь поиска модулей, путь
поиска исполняемых файлов, конфигурация по умолчанию. Все они смотрят рядом с
файлом или в текущий каталог, и все они срабатывают раньше вашего кода.

Второе: уникальное имя файла не спасает. Атакующему не нужно угадывать ваше имя —
ему достаточно занять имя того, что вы **загрузите**.

## Практические границы

- каталог создаётся под один запуск, права — только владельцу, удаляется
  целиком в блоке завершения, а не «когда-нибудь»;
- удаление в завершающем блоке обязательно и при сбое: иначе приватные каталоги
  копятся;
- то же касается путей поиска исполняемых файлов и переменных окружения: их
  чистят, а не наследуют;
- изоляция каталогом — **не замена** изоляции прав: она закрывает подмену
  зависимостей, а не выход в сеть или запись за пределы.

## Применимость

**Работает** для запуска чужого кода, распаковки чужих архивов, обработки чужих
файлов.

**Не работает** как единственная мера защиты: это один слой из нескольких.

**Признак проблемы:** временный файл создаётся общей функцией «дай мне временный
путь» и потом исполняется.
