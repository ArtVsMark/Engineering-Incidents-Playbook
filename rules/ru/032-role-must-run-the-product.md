# Если предмет роли наблюдаем в работающем продукте — роль обязана его запустить

**Правило.** Вывод, сделанный чтением кода там, где можно было запустить,
считается неполным.

## Инцидент

Аудит проводился чтением. Плотность находок измерили — и она оказалась
приговором методу:

| Способ | Подтверждённых важных находок |
|---|---|
| чтение кода | 8 на 489 находок |
| **запуск продукта** | **7 на 224** — плотность впятеро выше |
| **проход в браузере** | **33 находки** там, где чтение и `curl` дали 2 |

Браузерный проход добавили последним, почти для галочки. Он нашёл дефекты,
которые не видны в коде **принципиально**: поведение при узком экране, потеря
состояния, нечитаемые сообщения, недоступность с клавиатуры.

## Что значит «запустить» для разных ролей

| Роль | Что именно делает |
|---|---|
| тестировщик | прогоняет во всех режимах, ломает вход, смотрит отчёт |
| разработчик | воспроизводит дефект командой, а не выводит из кода |
| дизайнер, фронтенд | открывает **в браузере**: тёмная тема, вторая локаль, узкий экран, Tab-навигация |
| аналитик | сначала создаёт данные прогонами, потом сверяет показанное с фактом |
| безопасность | пытается нарушить границу, а не рассуждает о ней |
| релиз-инженер | прогоняет проверку на пустом входе, смотрит артефакт, а не конфиг |
| технический писатель | проходит описанный сценарий руками |

**Исключение** — роли, чей предмет вне работающего продукта: стратегия,
продвижение, исследование трендов. Они остаются читающими, и это нормально.

## Почему

Чтение кода отвечает на вопрос «что здесь написано». Пользователь сталкивается
с вопросом «что происходит» — а это результат взаимодействия кода со средой:
браузером, файловой системой, локалью, размером экрана, накопленными данными.

Целые классы дефектов **не существуют в коде**: отсутствующая обработка,
неудобный порядок, нечитаемый текст, невозможный сценарий.

## Применимость

**Работает** для любой проверки продукта: аудит, ревью крупной функции, разбор
жалобы.

**Не работает** для предметов, которые в продукте не наблюдаемы: стратегия,
лицензирование, планы.

**Требует** среды, где запуск возможен. Если её нет — это не повод читать, это
повод назвать слепую зону.
