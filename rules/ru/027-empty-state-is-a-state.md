# Пустое состояние надо объявлять явно

**Правило.** «Здесь сейчас пусто, дата» — это информация. Просто пустой файл —
неоднозначность.

## Инцидент

Очередь работ после крупного аудита хранилась в файле. Когда она отработала,
записи удалили — файл остался пустым.

Следующий, кто его открыл, не мог понять: очередь пуста, потому что всё сделано,
или потому что её ещё не заполнили? Или файл сломался при слиянии?

Тот же вопрос возникал с каталогом разборов: пусто — значит незакрытых нет, или
никто не проверял?

## Решение

Пустое состояние объявляется текстом:

```
Сейчас пусто — 2026-08-21. Все волны отработаны, новых не заведено.
```

Три вещи в одной строке: **факт** пустоты, **дата**, **причина**. Дата отвечает
на «давно ли», причина — на «почему».

То же в интерфейсах: «ничего не найдено» лучше пустого экрана, а «поиск не
запускался» лучше, чем «ничего не найдено».

## Почему

Отсутствие данных и отсутствие проверки выглядят одинаково — это тот же класс,
что «пустой список проверок означает всё хорошо».

Читатель, встретив пустоту, вынужден **достраивать объяснение сам**. Обычно он
достраивает оптимистично: раз пусто — значит порядок. Явная запись отбирает у
него эту возможность.

## Применимость

**Работает** для документов, очередей, отчётов, панелей, результатов поиска.

**Не работает** для структур, где пустота — норма и ни о чём не говорит:
временные каталоги, кэш.

**Дёшево:** одна строка. Возвращается при первом же вопросе «а тут точно ничего
нет?».
